# AI YouTube Shorts generator

Repo: https://github.com/PopcornParty/AI-video-gen

You do **not** need to install anything.
You do **not** need API keys.

## Make a Short on your phone

1. Open https://github.com/PopcornParty/AI-video-gen/actions
2. Tap **Generate Short**
3. Tap **Run workflow**
4. Type a topic
5. Tap the green **Run workflow** button
6. Wait a few minutes
7. Open the finished run
8. Download **video** if you only want the clip
9. Or download **youtube-short** for the video plus title, description, and hashtags

On iPhone:
- If Files says "bad message", download the artifact named **video** instead. That one is just the MP4.
- After unzipping **youtube-short**, tap `video.mp4` to watch it.
- Open the `.txt` files for the YouTube title, description, and hashtags.

Do not try to play the downloaded GitHub zip itself. Unzip it first, then open `video.mp4`.
