# AI YouTube Shorts generator

Minecraft only. No API keys. No install.

Open Actions → Generate Short → Run workflow.

## Modes

- **prompt** — talks about the exact text you type
- **category** — picks a Minecraft topic from a group
- **random** — random Minecraft topic
- **simulation** — silent visual only. No talking. No captions.

## Simulation types

When mode or category is `simulation`, pick a type:

- crystal
- redstone
- gravity
- portal
- life
- fire
- rain

Set **duration** to the length you want. Talking videos are padded with silence so they do not cut off at 13 seconds if you asked for 34.
