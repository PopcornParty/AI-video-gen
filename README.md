# AI YouTube Shorts generator

Repo: https://github.com/PopcornParty/AI-video-gen

You do **not** need to install anything on your computer.
You do **not** need API keys.

## How to make a Short

1. Open https://github.com/PopcornParty/AI-video-gen
2. Click the **Actions** tab
3. Click **Generate Short** in the left list
4. Click **Run workflow**
5. Type a topic, for example: Amazing space facts
6. Click the green **Run workflow** button
7. Wait a few minutes
8. Open the finished run
9. Download the artifact named **youtube-short**
10. Unzip it

The ZIP contains:

- `video.mp4` - the Short
- `youtube-title.txt` - YouTube title
- `youtube-description.txt` - YouTube description
- `youtube-hashtags.txt` - hashtags
- `youtube-tags.txt` - extra search tags

Upload `video.mp4` to YouTube Shorts and copy the text files into the title / description / tags boxes.

If Actions is disabled the first time: Settings -> Actions -> General -> Allow all actions.

This workflow uses only free public services (Wikipedia, Wikimedia, Microsoft Edge neural voices). No paid APIs and no secrets.
