# AI YouTube Shorts generator

You do not need to install anything.
You do not need API keys.

Open Actions → Generate Short → Run workflow.

## Pick how the topic is chosen

- **prompt** — type your own topic, example `Minecraft crystal PvP tips`
- **category** — pick a category such as `minecraft` or `space` and it chooses a topic in that category
- **random** — picks a random topic from the lineup

The catalog builds tens of thousands of topic lines from categories, subjects, and angles. It does **not** store 500,000 finished videos. Each run still writes a new Short with a hook, facts, voice, and pictures.

Facts stay locked to the chosen topic. Minecraft topics use a built-in Minecraft fact bank so crystal PvP does not turn into sky photos or enchanted-book pages.
