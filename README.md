# AI YouTube Shorts generator

Minecraft only.

You do not need to install anything.
You do not need API keys.

Open Actions → Generate Short → Run workflow.

## Topic options

- **prompt** — type a Minecraft topic, example `Minecraft crystal PvP tips`
- **category** — pick a Minecraft group:
  - crystal-pvp
  - pvp
  - redstone
  - nether
  - end
  - enchanting
  - mobs
  - items
  - building
- **random** — picks a random Minecraft topic
